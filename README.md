# ExamScan — 시험장 BLE 발신원 탐지 앱 (안드로이드 프로토타입 v0.1)

감독관이 폰을 들고 걸으면서, 신호(RSSI)가 급상승하는 지점을 찾아 발신 기기의 위치를 좁히는 앱입니다.

## 빌드 방법 (둘 중 하나)

**A. Android Studio**
1. 이 폴더를 Android Studio에서 `Open`.
2. Gradle 동기화가 끝나면 폰을 USB로 연결하고 ▶ Run.

**B. GitHub Actions (Android Studio 없이)**
1. 이 폴더를 GitHub 저장소에 push.
2. Actions 탭 → `Build APK` 실행 결과의 Artifacts에서 `app-debug.apk` 다운로드 후 폰에 설치.

요구 사항: 안드로이드 8.0 이상, 블루투스 켜짐, 위치 서비스 켜짐.

## 사용법

1. **스캔 시작** → '근처 기기'와 '정확한 위치' 권한을 모두 허용.
2. 시험 전 빈 교실에서 **현재 기기 제외**를 눌러 주변 환경(학교 장비, 제출된 폰 보관함)을 기준점으로 뺍니다.
3. 목록 위 **전체 그래프**에 기준 dBm 이상인 모든 기기의 최근 20초 신호가 겹쳐 그려집니다. 4초에 8dB 이상 오르는 기기는 굵은 빨간 선과 "▲급상승"으로 표시되고 폰이 두 번 진동합니다.
3-1. 시험 중 새로 뜨거나 급상승하는 기기가 있으면 목록에서 눌러 **추적 화면**으로 들어갑니다.
4. 폰을 가슴 높이로 들고 통로를 **천천히(초당 반 걸음)** 걷습니다. 진동이 빨라지는 쪽이 가까운 쪽입니다.
5. 화면에 "지금이 최고점" → 근처. "지나쳤습니다" → 되돌아가기. 방향을 바꿔 다시 접근할 때는 **최고점 리셋**.

소리는 기본으로 꺼져 있고 진동만 울립니다.

## 정확도를 위해 넣은 것

- 최고속 스캔 모드(LOW_LATENCY), 중복 패킷 전부 수신, 확장 광고(BLE 5) 포함.
- `neverForLocation`을 쓰지 않음 (쓰면 일부 광고 패킷이 걸러짐).
- 최근 1.2초의 상위 75% 값으로 평활 (순간적으로 값이 꺼지는 페이딩 완화).
- 화면 항상 켜짐, 20분마다 스캔 재시작 (안드로이드의 장시간 스캔 강등 회피).

## 알려진 한계 — 반드시 실측으로 확인할 것

- **실제 AI 안경으로 아직 검증하지 않았습니다.** 기종별로 연결 중에도 BLE 광고를 내는지, 광고 주기가 얼마인지 측정해야 합니다.
- `Devices.kt`의 스마트안경 제조사 ID·UUID는 공개 자료 기준 추정값입니다. 실물로 확인 후 갱신하세요.
- '현재 기기 제외'는 MAC 주소 기준입니다. 폰·안경은 주소를 주기적으로 바꾸므로(대개 15분 안팎) 제외했던 기기가 새 기기로 다시 뜰 수 있습니다.
- 거리대(1m 이내 등) 표시는 참고용입니다. 사람 몸과 책상이 신호를 10~20dB 가립니다.
- 블루투스 클래식 전용 기기, LTE 직결 기기, 전파를 내지 않는 기기는 잡지 못합니다.
