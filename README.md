# ExamScan — 시험장 BLE 발신원 탐지 앱 (안드로이드 프로토타입 v0.1)

감독관이 폰을 들고 걸으면서, 신호(RSSI)가 급상승하는 지점을 찾아 발신 기기의 위치를 좁히는 앱입니다.

## 빌드 방법 (둘 중 하나)

**A. Android Studio**
1. 이 폴더를 Android Studio에서 `Open`.
2. Gradle 동기화가 끝나면 폰을 USB로 연결하고 ▶ Run.

**B. GitHub Actions (Android Studio 없이)**
1. 이 폴더를 GitHub 저장소에 push.
2. Actions 탭 → `Build APK` 실행 결과의 Artifacts에서 `app-debug.apk` 다운로드 후 폰에 설치.

요구 사항: 안드로이드 8.0 이상, 블루투스 켜짐, 위치 서비스 켜짐.

## 사용법

1. **스캔 시작** → '근처 기기'와 '정확한 위치' 권한을 모두 허용.
2. **보정(처음 한 번, 정확도에 가장 중요):** 이어폰 같은 아는 기기를 폰에서 정확히 1m에 두고, 반경을 넓혀 목록에서 그 기기를 눌러 추적 화면으로 들어간 뒤, 폰을 5초쯤 가만히 두고 **"정확히 1m 거리 (보정)"** 를 누릅니다. 보정값은 저장됩니다.
3. 시험 전 빈 교실에서 **현재 기기 제외**를 눌러 주변 환경(학교 장비, 제출된 폰 보관함)을 뺍니다.
4. **감지 반경**(기본 1m, 0.5~10m)을 정하고 통로를 천천히 걷습니다. 반경 안에 기기가 들어오면 폰이 두 번 진동하고, 전체 그래프에 선이 나타납니다. 그래프는 위쪽이 가까운 쪽이며, 빠르게 가까워지는 기기는 굵은 빨간 선입니다.
5. 목록에서 기기를 누르면 추적 화면: 추정 거리가 크게 표시되고 가까울수록 진동이 빨라집니다. "지금이 가장 가깝습니다" → 근처. "지나쳤습니다" → 되돌아가기.

소리는 기본으로 꺼져 있고 진동만 울립니다.

## 거리 추정 방식

- **칼만 필터**로 RSSI 잡음을 줄입니다. 가속도계로 폰이 움직이는지 감지해, 걷는 중에는 빠르게 따라가고 멈추면 강하게 평활합니다(상태 줄의 "이동 중 / 정지(정밀)").
- 신호가 순간적으로 꺼지는 값(다중경로 페이딩)과 한 번뿐인 급등은 덜 믿습니다.
- **로그-거리 경로손실 모델** `d = 10^((P1m − RSSI) / (10·n))`, n = 2.2. 광고 패킷에 송신 출력이 실려 있으면 그 값을 기준으로 씁니다.
- 반경 판정에는 히스테리시스(들어올 때 R, 나갈 때 1.3R)를 둬서 경계에서 깜빡이지 않습니다.
- 스캔은 최고속 모드, 확장 광고 포함, 20분마다 재시작.

## 알려진 한계 — 반드시 실측으로 확인할 것

- **표시되는 거리는 추정값입니다.** 기기마다 송신 출력이 달라(대개 ±10dB) 보정 후에도 실제 거리의 0.5~2배 범위로 벗어날 수 있고, 사람 몸이 사이에 있으면 실제보다 멀게 나옵니다. BLE 신호 세기만으로 2m 이내 여부를 안정적으로 가리기 어렵다는 것은 접촉 추적 앱 실측 연구(Leith & Farrell, 2020)에서도 확인된 한계입니다.
- 그래서 절대 거리보다 **"가까워질수록 값이 줄어드는 변화"** 와 최근접 지점이 더 믿을 만합니다.
- 실제 AI 안경으로 아직 검증하지 않았습니다. `Devices.kt`의 스마트안경 제조사 ID·UUID는 추정값입니다.
- '현재 기기 제외'는 MAC 주소 기준이라, 주소가 바뀌면(대개 15분 안팎) 다시 뜰 수 있습니다.
- 블루투스 클래식 전용 기기, LTE 직결 기기, 전파를 내지 않는 기기는 잡지 못합니다.
